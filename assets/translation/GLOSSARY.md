# 갤럭시 엔젤 번역 용어집

번역기가 읽는 확정 표기는 `glossary.tsv`에 있다.

## 기준

- 등장인물 표기는 사용자가 지정한 나무위키 `갤럭시 엔젤/등장인물` 문서를 기준으로
  하고, 현재 PS2판 원문에서 실제 표기와 빈도를 대조했다.
- 메카 표기는 사용자가 지정한 나무위키 `갤럭시 엔젤/메카 설정` 중 GA 시리즈와
  기타 메카만 대상으로 삼았다. RA 시리즈는 포함하지 않는다.
- 현재 작품 원문에 등장하는 문장기는 GA-001~GA-005다. GA-006 샤프 슈터는 후속작
  참고용으로만 남기고 자동 번역 매칭 대상에서는 사실상 사용되지 않는다.
- `・`가 들어간 원문은 번역에서도 같은 위치에 `・`를 유지한다.
- `ミルフィーユ`는 `밀피유`, 작중 애칭 `ミルフィー`는 `밀피`로 구분한다.
- `エンジェル隊`는 일반 표면형 `엔젤대`, 정식 부대명 `ムーンエンジェル`은
  `문 엔젤대`로 구분한다.
- `クリオム`은 반드시 `크리옴`으로 표기한다.
- `アルモ`는 반드시 `아르모`, `ローム星系`는 반드시 `롬 성계`로 표기한다.

## 출처와 검증 상태

- 지정 문서: <https://namu.wiki/w/갤럭시%20엔젤/등장인물>
- 지정 문서: <https://namu.wiki/w/갤럭시%20엔젤/메카%20설정>
- 원문 모집단: `segments/*.json` 210개, 대사 18,165단위
- 나무위키 본문은 자동 접근이 차단되어 검색 색인과 게임 원문을 함께 대조했다.
  따라서 `크로미에・콰르크`, `시그루트・지더마이어`처럼 빈도가 낮은 조연의 한글
  표기는 전체 번역 전 표본 검수 때 한 번 더 확인한다.

## 번역기 적용 규칙

1. 긴 원문 표기부터 매칭한다. 예: `タクト・マイヤーズ`를 `タクト`보다 먼저 본다.
2. 원문에 전체 이름이 없으면 번역에도 성을 임의로 추가하지 않는다.
3. 원문에 호칭이 있을 때만 한국어 호칭을 붙이며 `さん→씨`, `君/くん→군`, `ちゃん→쨩`, `様/さま→님`, `どの/殿→나리`, `氏→씨`, `嬢→양`으로 대응한다. 이름·직책에 붙은 접미 호칭을 `분`, `아가씨`, `님` 등으로 임의 승격·변형하지 않는다.
4. `先生`, `陛下`, `閣下`는 각각 `선생님`, `폐하`, `각하`로 고정한다. 이는 접미사 치환이 아니라 고정 칭호 번역이다.
5. 군 직책은 `司令→사령관`, `総司令→총사령관`, `副司令→부사령관`으로 고정한다. 원문 직책 뒤에 접미 호칭이 없으면 `님`, `씨`, `나리`를 추가하지 않고, `司令さん→사령관 씨`, `司令官どの→사령관 나리`, `司令様→사령관님`처럼 접미사가 실제로 있을 때만 결합한다. 같은 기준을 `准将`, `大将`, `班長`, `会長`, `部長`, `皇子` 등 모든 직책에 적용한다.
6. `営業部長さん→영업부장 씨`, `班長さん→반장 씨`, `ミント嬢→민트 양`처럼 직책·인명 뒤 호칭은 원문 등급을 그대로 보존한다. 반면 `お父さん`, `お兄さま`, `お客様`, `旦那様`, `お嬢様`처럼 단어 전체가 관용 호칭인 경우에는 자연스러운 한국어 관용 호칭으로 번역한다.
7. `司令部→사령부`, `司令塔→사령탑`처럼 복합어는 직책과 구분하고 `辞令`을 `사령`으로 오역하지 않는다.
8. RA 계열 명칭은 이 작품의 용어집에 새로 추가하지 않는다.
9. 확정 표기를 바꿀 때는 번역 전체의 조사와 새 한글 글리프 수를 다시 검사한다.
