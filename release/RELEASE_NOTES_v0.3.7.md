## v0.3.7 번역·UI 후속 수정 및 저장 제목 안정화

- 시리즈 공통 용어를 **쿵후 파이터**로 통일했습니다. 대사·용어집·이미지·관련 런타임 복사본을 함께 반영했습니다.
- 제보된 띄어쓰기/표기와 전투 대사 창 넘침을 점검하고, 전투 대사의 기존 3줄 표시 한도를 유지했습니다.
- 같은 UI의 TEX 형식/크기 불일치 복사본 22개를 정상화하고, 런타임 복사본 1,417개의 크기 정보를 실제 데이터와 동기화했습니다. 해당 수정에서 리소스 주소는 이동하지 않았습니다.
- 현재 수동 편집 이미지와 자막 영상을 보존했습니다. 자막 영상 24개와 자막 제외 원본 영상 6개의 최종 ISO 해시 일치를 확인했습니다.
- 저장 제목의 24바이트 복사 시 2바이트 문자가 중간에서 잘리지 않도록 보호했습니다. 한글 코드 배치를 고정하고, 미등록 글자가 있으면 빌드를 중단하도록 했습니다.

### 세이브와 진행 불가 안내

프리징은 관련 원인 수정 후 개선된 것으로 보이지만, 모든 경로에서 완전히 해결됐다고 확정할 수는 없습니다. 향후 같은 증상이 다시 제보되면 당시 세이브와 실행 환경을 기준으로 재확인하겠습니다.

기존 세이브/세이브스테이트에는 이전 문자 코드로 된 제목이 남을 수 있고, 불러온 뒤 다시 저장해도 이어질 수 있습니다. 기존 제목의 자동 변환은 포함하지 않았습니다. 원본 메모리카드를 백업해 주세요.

### 검증과 상세 내역

일본판 원본에 배포 xdelta를 다시 적용하여 검증 ISO의 SHA-256과 일치하는지 확인한 뒤 배포합니다. ISO 자체는 배포하지 않습니다. 원본과 결과 ISO 및 패치 해시는 첨부한 `README.txt`, `SHA256SUMS.txt`에 있습니다.

항목별 변경 전후와 적용하지 않은 항목의 사유는 [후속 검수 기록](https://github.com/TAMTAMQ/galaxy-angel-korean-translation-patch/blob/v0.3.7/SERIES_ISSUE_FOLLOWUP_20261018.md), [저장 제목 수정 기록](https://github.com/TAMTAMQ/galaxy-angel-korean-translation-patch/blob/v0.3.7/SAVE_TITLE_FIX_20261019.md)을 참고해 주세요. 이 릴리즈 안내가 앞선 기록의 '로컬 ISO만 생성' 상태를 대체합니다.
