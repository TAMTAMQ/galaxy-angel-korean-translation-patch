# 갤럭시 엔젤 한국어 번역 패치

> 🙏 이 패치는 **완벽한 번역을 기대하시는 분보다는, AI 번역 기반이라 발생할 수 있는 사소한 오역이나 어색한 표현이 있어도 크게 개의치 않고 플레이하실 수 있는 분들을 위한 패치**입니다.

> ⚠️ **완역 패치가 아닙니다.** 본편 대사·선택지·전투 대사·UI 이미지는 번역되어 있지만, 아직 찾지 못했거나 처리가 어려운 일부 그래픽 문구는 원문으로 남아 있을 수 있습니다.

PlayStation 2용 『ギャラクシーエンジェル』 일본판(시리즈 1편)의 비공식 팬 한국어 번역 패치입니다.

- 본편 시나리오 210개 블록, 전투 대사, 미니게임, 시스템 메시지를 다룹니다.
- 완성형 한글을 게임 실행 파일 `SLPM_652.54`의 폰트 테이블에 새로 그려 넣는 방식으로 표시합니다.
- UI·미니게임 이미지의 일본어도 원본 팔레트·픽셀 포맷 그대로 다시 그려 넣습니다.

> 💬 오역, 미번역 문구, 버그를 발견하시면 [Issues 탭](../../issues)에 제보해 주세요.

## 2. 패치 적용

1. [Releases](../../releases)에서 `galaxy_angel_ps2_kr_v0.1.xdelta`를 받습니다.
2. xdelta3 또는 xdelta 패치를 지원하는 프로그램(예: Delta Patcher)에서 **원본 ISO를 Source로** 지정해 적용합니다.

   ```bash
   xdelta3 -d -s "Galaxy Angel (Japan).iso" \
       galaxy_angel_ps2_kr_v0.1.xdelta "Galaxy_Angel_KO_v0.1.iso"
   ```

3. 결과 ISO의 SHA-256이 위 값과 같은지 확인하세요.

패치 파일 자체의 SHA-256은 `aefa2483e87ad8fe16f9da4443e1fdab9dc91162d0e15d42fab567ab3ec3f49c` 입니다.

원본 게임 파일(ISO, BIOS 등)은 이 저장소에 포함되어 있지 않습니다. 정당하게 소유한 정품 이미지에만 적용하세요.

### 아직 번역 안 된 것 (알려진 미해결 항목)

- 실행 파일과 비압축 영역에서 찾은 검토 후보 1,070개는 개발 로그·문자표·오검출이 섞여 있어 안전을 위해 원문을 유지합니다.
- 개발 주석, 설정 주석, MINI 스크립트의 `#` 주석은 화면에 나오지 않아 제외했습니다. `GADAT002.DAT`에 남은 일본어 30건도 `pbs08_01.rat ;ＲＡＴ－811_…` 형태의 리소스 경로 주석입니다.
- 그 외 아직 찾지 못한 그래픽 문구가 있을 수 있습니다.

이후 고친 것 두 가지를 적어 둡니다.

- **전투 조작 안내** — `GADAT002.DAT`와 그 `SLGINIT.DAT` 런타임 사본에 있는 8종(각 23곳)이
  일본어였습니다. OFF·닫기 쪽만 번역돼 있고 짝이 되는 ON·열기 쪽이 통째로 빠져 있었습니다.
- **음성만 재생하는 빈 대사** — 원문이 전각 공백 한 칸(`　`)인 대사에서 그 공백이 지워져 표시할 글자가
  하나도 없는 줄이 79건 있었습니다. 이러면 대사 표시가 끝나지 않아 진행하려면 버튼을 한 번 더 눌러야
  합니다. 원문 여백대로 되돌리고, 검증에 "빈 표시 줄 금지" 규칙을 넣어 재발을 막았습니다.

## 4. 직접 빌드하기

**요구 사항**: Python 3, `pip install pillow numpy opencv-python pyxdelta`

`assets/translation/`과 `tools/`만으로는 바로 빌드되지 않습니다. 원본 ISO에서 추출한 데이터가 함께 필요하며, 저작권이 있는 원본 데이터라 저장소에 포함되어 있지 않습니다.

| 항목 | 출처 |
| --- | --- |
| `tools/`, `assets/translation/` | 이 저장소 |
| `source/`, 추출 이미지 | **직접 준비** — 정품 ISO에서 추출 |
| 원본 일본판 ISO | **직접 준비** |

빌드는 `build_patch.ps1`이 각 단계를 순서대로 호출합니다. 배포용 패치 생성과, **그 패치를 적용해 최종 ISO를 만드는 것**은 아래와 같이 합니다.

```bash
python tools/eternal_lovers_make_release.py \
    --original-iso "Galaxy Angel (Japan).iso" \
    --patched-iso "build/Galaxy Angel (Korean).iso" \
    --release-dir release --version v0.1 \
    --title "Galaxy Angel" --slug galaxy_angel

python tools/galaxy_angel_apply_release_patch.py \
    --original-iso "Galaxy Angel (Japan).iso" \
    --release-dir release --output-iso release/Galaxy_Angel_KO_v0.1.iso
```

`galaxy_angel_apply_release_patch.py`는 원본 ISO 해시를 `release.json`과 대조하고, 적용 결과의 해시·크기까지 다시 확인합니다.

## 5. 개발 내역

- **중앙 `IDX.DAT` 인덱스**: 각 GADAT 컨테이너의 로컬 PIDX 외에 `IDX.DAT`에도 파일 ID·내부 오프셋·해제 크기·압축 크기의 중앙 복사본이 있습니다. 로컬만 갱신하면 게임이 원래 압축 크기만 읽어 시나리오 버퍼 뒷부분이 `0xAA`로 남고 진행이 멈춥니다. 정지 지점의 EE 메모리를 직접 읽어 규명했습니다.

- **컨테이너 고정 베이스**: 스크립트 엔진은 그룹 간 호출에서 ISO9660을 우회하고 컨테이너의 **원래 LBA를 고정 베이스로** 씁니다. 일반 대사는 새 위치를 따라가지만 선택지와 전투 전환은 원래 섹터를 읽어 멈춥니다. 그래서 `GADAT001.DAT`를 원래 extent에 두고, 원래 할당을 넘는 블록만 디스크 뒤쪽 backing 사본으로 우회시킵니다(ISO9660의 겹치는 extent 활용).

- **블록 위치 보존**: 번역 블록을 재배치·압축하면 관리 블록(`0x149800`)과 ID 인덱스(`0x14E000`)의 내부 위치까지 바뀝니다. 슬롯에 들어가는 블록은 제자리에 두고 넘치는 블록만 옮기는 방식으로 원본 물리 배치를 유지합니다.

- **전투 텍스트 파서**: `[MESSAGE]` 설정값 파서가 ASCII 공백에서 값을 끝내기 때문에, 띄어쓰기가 있는 한국어는 첫 단어만 표시됩니다. 공백을 CP932 단일 바이트 블랭크로 인코딩해 해결했습니다.

- **런타임 사본**: 전투 대사는 `SLGINIT.DAT`에도 사본이 있어 `GADAT002`와 반드시 함께 패치해야 합니다. 사본을 ISO 끝으로 보내면 전투 초기화 경로와 충돌해 게임오버로 빠지므로, 뱅크 내부에서 원본 크기를 유지한 채 재패킹합니다.

- **이미지**: 4bpp/8bpp AGI와 PSMT4/PSMT8 TAG를 원본 압축 방식으로 재인코딩하며, 원본 팔레트로 재양자화하므로 이미지 크기·픽셀 포맷은 변하지 않습니다.

자세한 시간순 기록은 [STATUS.md](STATUS.md)에 있습니다.

## 6. 저장소 구성

- `tools/` — 추출·번역 반영·폰트 생성·검증용 파이썬 스크립트
- `assets/translation/` — 번역 텍스트 (이 폴더를 편집하는 것이 번역 작업의 전부입니다)
- `STATUS.md` — 개발 기록

저장소에 포함되지 않는 것 (`.gitignore` 참고, 직접 빌드 시 원본 디스크에서 재추출):

- `source/`, `original/` — 원본 게임에서 추출한 바이너리
- 추출·번역 이미지
- `build/`, `release/` — 빌드 결과물 (패치는 Releases에 올립니다)

## 7. 라이선스 / 권리

**누구나 자유롭게 사용하셔도 됩니다.** 별도의 허락을 구할 필요 없이, 아래 조건(비영리 팬 번역 목적, 정품 게임 소유)만 지켜주시면 내려받아 적용하거나 포크해서 참고·수정하실 수 있습니다.

- **도구 소스코드** (`tools/*.py`): [MIT 라이선스](LICENSE)
- **번역 텍스트** (`assets/translation/`): 비영리 팬 번역 목적으로 자유롭게 공유·수정하실 수 있으나, 게임을 판매하거나 상업적으로 이용하는 용도로는 사용하지 말아주세요.
- **게임 원본 데이터**: 『갤럭시 엔젤』의 저작권은 BROCCOLI에 있습니다. 이 저장소는 원본 게임 파일(디스크 이미지, 실행 파일, 폰트, 대사 바이너리 등)을 포함하거나 배포하지 않으며, 패치는 반드시 정식 발매된 게임을 정당하게 소유한 상태에서 개인적으로 적용하는 용도로만 사용해주세요.
